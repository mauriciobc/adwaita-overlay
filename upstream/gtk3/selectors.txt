# The GTK3 selector contract. One selector atom per line, sorted.
#
# NOT all 2001 atoms of GTK3's Adwaita — the front is a recompile of that
# sheet, not an override of it, so there is nothing hand-written to list. What
# is worth watching is the surface tools/build-gtk3 MODIFIES: the declarations
# whose value is the accent, and which therefore stop tracking the system
# accent if the atom that carries them disappears. That set is exactly what
# tools/gtk3-accent-sites enumerates (373 declarations, 434 distinct atoms,
# light + dark), and it is what is listed here.
#
# The failure this catches is the quiet one: GTK removes or renames a
# selector, build-gtk3's substitution table no longer matches, and one widget
# silently keeps #3584e4 baked in while every other widget follows the system
# accent. Nothing crashes; one control is just permanently the wrong colour.
#
# Generated from: tools/gtk3-accent-sites | cut -f2 | tr , '\n' | sort -u
# Regenerate and re-read the header when the pin moves (BACKLOG G6).
# Rules:
#   - update this file and the pinned tag in the same commit
#   - entries are ATOMS as the extraction heuristic sees them, so they match
#     upstream/selectors.txt in style and compare against the same set
#   - "@define-color" is excluded: it is a colour definition line that
